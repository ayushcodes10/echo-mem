# source-command-hive-mind-hive-mind

Use this skill when the user asks to run the migrated source command `hive-mind-hive-mind`.

## Command Template

# hive-mind

Hive Mind collective intelligence system for advanced swarm coordination.

## Usage
```bash
npx Codex-flow hive-mind [subcommand] [options]
```

## Subcommands
- `init` - Initialize hive mind system
- `spawn` - Spawn hive mind swarm
- `status` - Show hive mind status
- `resume` - Resume paused session
- `stop` - Stop running session

## Examples
```bash
# Initialize hive mind
npx Codex-flow hive-mind init

# Spawn swarm
npx Codex-flow hive-mind spawn "Build microservices"

# Check status
npx Codex-flow hive-mind status
```
