# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://github.com/ayushcodes10/echo-mem/security/advisories/new)
for this repository. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant logs, PoC code, or configuration

We'll acknowledge reports and work on a fix; timelines depend on severity.

## Supported Versions

This project is pre-1.0 and under active development; only the latest commit on `main`
is supported. There is no stable release yet.
